# SQL Retail & Sales Data Analysis Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and focused on using **SQL** to explore, analyse, and extract insights from retail and sales datasets. The project involved querying relational databases, combining data from multiple tables, and generating meaningful business insights to support decision-making.

## Skills Demonstrated

### Data Retrieval & Filtering
- Used `SELECT` statements to retrieve specific data from database tables.
- Applied `WHERE` clauses to filter records based on business requirements.
- Queried customer, product, order, and sales data to answer real-world business questions.

### Data Sorting & Organisation
- Utilised `ORDER BY` to sort datasets in ascending and descending order.
- Organised customer, product, and sales information to improve reporting and analysis.

### Data Aggregation & Analysis
- Applied `GROUP BY` to summarise and aggregate data.
- Used functions such as `COUNT()`, `SUM()`, and `AVG()` to analyse sales performance, product volumes, and customer activity.
- Generated category-level and product-level insights from transactional data.

### Working with Relational Databases
- Performed table `JOINs` to combine data across multiple related tables.
- Used `INNER JOIN`, `LEFT JOIN`, and multi-table joins to connect customers, orders, products, suppliers, and categories.
- Developed an understanding of primary keys, foreign keys, and database relationships.

## Key Analysis Areas

- Customer purchasing behaviour
- Product sales performance
- Order trends and reporting
- Supplier and category analysis
- Retail inventory insights
- Sales volume and revenue-related metrics

## Tools & Technologies
- SQL
- Supabase
- Relational Databases
- Northwind Sample Database

## Learning Outcomes
Through this project, I strengthened my ability to write efficient SQL queries, work with relational databases, and transform raw retail and sales data into actionable business insights. The project improved my understanding of database structures, data relationships, and analytical techniques commonly used in data-driven environments.
